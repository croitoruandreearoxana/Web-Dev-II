# Web Refresher: EcoPulse Sustainable Living Guide

## Reflection

The creation of the EcoPulse guide has allowed me to practice harmonising visual hierarchy with semantic HTML structure. By marking out the page using `<header>`, `<main>`, `<article>` and `<form>` tags, the page contet becomes clean and easy to navigate. The use of CSS variables to distribute a cohesive sage and forest green palette a has given the interface warmth while maintaining strong text contrast and accessibility.

The primary difficulty was related to balancing interactive DOM state with input validation logic in JavaScript. The commitment form accurately intercepted submissions, validated missing fields and displayed controlled dynamic confirmation messages without triggering a full page reload that require testing multiple event branches.

For Web Development II, I want to strengthen my understanding of modern JavaScript form architectures and state binding patterns so that complex client interactions can be handled cleanly in upcoming React components.
